# Data provenance and reuse

This project includes the unchanged `raw/bank-full.csv` from the **UCI Machine Learning Repository — Bank Marketing** dataset, older 45,211-row `bank-full.csv` version (not `bank-additional-full.csv`). The raw file has 16 original predictor columns plus the binary `y` target and uses semicolons as separators.

**Required attribution:** Moro, S., Rita, P., & Cortez, P. (2014). *Bank Marketing* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306

- Dataset page: https://archive.ics.uci.edu/dataset/222/bank+marketing
- Dataset license: Creative Commons Attribution 4.0 International (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/
- The dataset is from historical Portuguese bank direct-marketing records. The original CSV was not modified by this portfolio project.
- The analysis does not claim real-time production access, unique customer identities, experimental results, or a bank's measured performance improvement.

Attribution and license above apply to **the source dataset**, not automatically to the independently authored project source files and dashboard.
